# SAFE on RoboCasa full report

This directory is the source package for the complete July 13-August 23, 2026 SAFE/RoboCasa technical report, including the final RLDX supported-20 natural-data experiment, the frozen Xiaomi matched-FPR calibration and prospective shadow test, the five-composite-task terminal-versus-subtask-label experiment, and the full-parent stage-aware developmental follow-up.

- `main.tex`: LaTeX source.
- `figures/`: selected figures from the checksum-verified artifact bundle, deterministic 6 August updates, the 15 August SAFE20 calibration outputs, the frozen 16 August Xiaomi calibration bundle, and the 17 August prospective task-scope comparison.
- `tables/`: machine-readable CSV evidence for rollout SAFE, the V2 representation screen, the frozen parent-aware analysis, Xiaomi prospective outcomes, and the full-parent stage-aware selection/calibration audit.
- `generate_update_figures.py`: regenerates the report-owned comparison, frozen-prefix, and Xiaomi prospective task-scope figures from the report tables.
- `chart_map.md`: source and interpretation for every included figure.
- `build/`: LaTeX compilation output (generated).

The Xiaomi visual bundle is generated by
`robocasa/recovery/safe/create_xr1_matched_fpr_visual_bundle.py`. It packages
six raw representative rollouts and six synchronized annotated MP4s. The
annotations are rendered by `xr1_matched_fpr_video.py` from the recorded
inference environment steps, video-frame stride, normalized SAFE trajectory,
time-risk trajectory, and frozen thresholds; no simulator replay is required.

The final validated PDF is also copied to `output/pdf/safe_robocasa_complete_experimental_report.pdf`.

The five-task terminal-versus-subtask result is presented as two compact
tables rather than a new chart: the evidentiary object is a four-treatment by
four-prefix exact comparison, and a plot would obscure the selected
configuration and development-to-outer transfer values.

The full-parent stage-aware result is likewise reported with explicit setup,
aggregate selection, per-task, and calibration-support tables. Its 0.696
prefix-1/2 ROC-AUC is a development-selection result; the report deliberately
does not present it as held-out validation because the locked 80-parent outer
set was not scored and only 18 successful calibration parents were available.
